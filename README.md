# XMUM

Windows (PowerShell):

```
irm https://github.com/lowkeyzezz/xmum-app/releases/latest/download/launch.ps1 | iex
```

Mac / Linux (Terminal):

```
curl -fsSL https://github.com/lowkeyzezz/xmum-app/releases/latest/download/launch.sh | sh
```

You need the access code you were given. `accounts.dat` is encrypted.
